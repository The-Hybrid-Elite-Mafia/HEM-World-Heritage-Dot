# World Heritage Workstation 0.4.0 — engineering candidate

This is an isolated, compiled candidate, not an installed or user-approved replacement. Installed v0.3.3 and its data remain untouched. Do not infer hardware playback from the offline tests.

## Build
Windows x64, C++23, AVX2 CPU required. No JUCE/Qt. Direct2D/DirectWrite and Windows SDK libraries. Tested compiler: LLVM-MinGW 20261020, `build.ps1 -Compiler <absolute clang++.exe>`. CMake supports MSVC x64 with `/arch:AVX2 /utf-8`; The installed MSVC19.29 (VS2019) also built the app and passed the offline suite using /std:c++latest /arch:AVX2. This older compiler does not verify the requested C++23-capable MSVC toolchain; a modern MSVC toolset remains required for that acceptance item. CMake configuration: `cmake -S . -B ../msvc-build -A x64`, then `cmake --build ../msvc-build --config Release` from a suitable Windows SDK/MSVC environment. No toolchain installation is included.

## Runtime layout and safety
The candidate expects `library/` beside its executable. The complete existing 402-preset library is not duplicated into this small source/build archive. Restore the already backed-up library separately before evaluating library browsing. No installer is applied by this delivery. The existing library contains 79 named types (78 if nylon/steel guitars are merged taxonomically), not every possible acoustic instrument.
Copy a desired `audio-preferences.conf` beside the candidate; no audio starts on launch. Missing configuration defaults to WASAPI shared, stopped. Invalid configuration blocks Connect until a valid choice is explicitly saved. Save selection and Connect are separate. ASIO is registry-discovered, with no automatic fallback. ASIO requires the driver's current rate to be 48 kHz; WASAPI rejects unsupported 48 kHz formats. No Windows routing is changed. Real hardware compatibility, driver initialization and latency remain untested.

## Controls and sample origin
Custom single-window canvas draws panels, banks, text entry, folder browser, zone editor, rotary knobs, meters and 88 keys. No native child widgets or native file dialogs are instantiated. The exact production draw() was rendered with Direct2D/WIC without an HWND at1366x768,1920x1080,2560x1600. The1366 and2560 images were visually inspected: primary controls fit. Live interaction and Windows per-monitor DPI remain untested. Folder import reads WAV/FLAC/AIFF, infers note names/velocity anchors/RR, and keeps original recordings immutable. Ambiguous filenames default to MIDI60 and require mapping review; folder automation cannot prove an instrument's identity. Import is capped at4096 zones; partial failures appear in status.
Right-click zones to edit root/key range/velocity/RR/release flag. Left click zones or keyboard auditions only through an explicitly connected output. A/W/S/E/D/F/T/G/Y/H/U/J/K play notes; Z/X change octave. Sustain and velocity controls are available. SAVE INSTRUMENT now asynchronously exports a new named folder under library/User Instruments. It copies original recordings into recordings/, verifies SHA-256 before/after copy, deduplicates repeated sources, saves relative preset paths, retains metadata and writes SHA256SUMS.txt plus RESTORE.txt. Move the whole folder together. Existing packs are never overwritten; originals are never written. A failed export leaves a clearly named .partial staging folder for inspection and never publishes an incomplete final pack. The low-level legacy savePreset API still supports reference-only files; the workstation Save action uses portable export.

## DSP ranges
Hardness0–100% (transient difference accent); Strike Window1–250ms (excitation window); Resonance0–100% (waveguide return mix); Detune−50–+50cents (fractional delay); Stiffness0–100% (modal spacing and delay damping); Decay0.05–12s (feedback/modal damping); Sympathetic0–100% (recording-driven modal excitation); Release Noise0–100% (gain of explicitly mapped recorded release files). Blend0–100% selects recording to sample-excited waveguide/modal output. Physics bypass returns dry processing. Default dry processing is bit-exact in the tested DSP fixture. No independent oscillator, noise generator, synthetic sample bank, DAW or stems.

Release Noise is unavailable when no release files are mapped. Filename `_release`/`_rel` is a mapping hint, not provenance proof. The release test reuses a real recording solely as a routing fixture; it does not validate that recording as acoustic release noise. Eight modes use AVX2. Numerical finite-output tests do not establish acoustic realism. Legacy v1–v4 files load; legacy friction is reserved/ignored and old resonance sound is not preserved with blend0. This is an explicitly unresolved compatibility difference.

## Telemetry and streaming
Live values use engine state/counters; stopped rate/buffer are unavailable. CPU is process CPU averaged across logical processors, not real-time callback CPU. DECODED MiB/s is decoded stereo PCM throughput, not physical disk traffic. Peak meters measure engine PCM, not measured hardware output. Reported buffer milliseconds omit producer queue, driver, OS and hardware latency; zero-latency cannot be guaranteed. WAV/AIFF use bounded memory-mapped views/double decoded pages; FLAC predecodes to temporary PCM cache rather than direct compressed-file streaming. The worker supplies a resident atomic SPSC PCM ring; file IO/DSP do not run inside the ASIO callback. Physical-page residency/hardware callback timing has not been revalidated for this candidate.

## Factory release audit
All402 current factory presets are v4 with zero explicit recorded-release zones; no release/rel filename candidates were found. Their releaseSeconds values are amplitude envelopes, not release recordings. Release Noise therefore displays NO RELEASE MAPPED for these factory presets. Actual user-supplied release recordings are retained through portable save/load. No releases were fabricated.

## Legacy preset preservation (revision 5)
Preset versions 3 and 4 now retain their original sample-only post-mix resonance, tension, strike and friction processor. New saves use format 6 with a persisted legacy-mode flag. Four non-neutral/neutral v3 migration cases with overlapping notes are byte-identical to the separately compiled v0.3.3 engine and remain byte-identical after v6 save/reload. Existing source presets are not rewritten. New physical modeling is available through the blend control while the saved legacy processor remains post-mix; bypass disables the new physics, not the legacy preset processing. No oscillator or generated noise is used. Factory release articulation remains NO RELEASE MAPPED because none of the402 factory presets maps recorded release samples. Telemetry reports DECODED MiB/s, not physical disk throughput.
